Sources & coverage

Searchable commands, subcommands and task recipes. This is not an exhaustive list of every tool or every option. Platform collections follow the source; common tools are not guaranteed to work on every operating system.

Content

The English tldr-pages collection is adapted under CC BY 4.0. Supplementary CLIx references and guides link to their documentation individually. Task recipes are labelled separately from command references; counts include both. Topic classifications are curated navigation aids, not security ratings.

Before use

Check your installed version, operating system, permissions and placeholders. Some examples change or delete data. CLIx never executes commands. Security work must stay within an authorised scope. Research and OPSEC guidance does not guarantee anonymity or system security.

Update and storage

Run python scripts/sync.py to refresh the upstream catalogue. The local security pack remains separate. Bookmarks stay in this browser; private mode may limit storage. Commands and guides work offline. Documentation links require internet access.
